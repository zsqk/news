# Zeit-now部署靜態項目
現在ZEIT 是一個雲平臺靜態站點和無服務器功能完美地與您的工作流程適合。它使開發人員可以託管Jamstack網站和Web服務，這些網站和Web服務可以立即部署，自動擴展並且不需要任何監督，而且都無需配置。

#### 註冊
註冊鏈接：<https://zeit.co/>，首先需要前往zeit官網進行用戶註冊，當然我們也可以用gitlab，github等等方式來進行登錄，這也是使用該工具的一個前提條件

#### 安裝
在命令行工具執行`npm install now -g`，進行now的全局安裝。

#### 使用方法
##### 本地命令行
- 1.命令行工具進入項目，運行`now`命令
- 2.根據提示進行配置
- 3.配置完成後會看到一行`products`提示網站鏈接地址，複製該地址，即可直接訪問部署的項目
##### zeit官網項目部署
- 1.進入<https://zeit.co/>並登錄。
- 2.進入個人`Owerview`頁面，選擇Import Project
- 3.可從gitlab,github等導入已有項目，或者可以選擇模板導入項目
