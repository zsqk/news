看 GitHub 很少會看個人頁.

知道 Arctic Code Vault Contributor 這件事還是在[社區][1]中.

社區中大多數人都有, 我也不例外.

<img width="634" alt="Screen Shot 2020-07-17 at 17 59 36" src="https://user-images.githubusercontent.com/499364/87774569-48f5ce00-c857-11ea-93e3-60de10e17291.png">

然後看了 [GitHub blog][2] 瞭解了更多.

在2020年2月2日這一天, GitHub 將所有活躍的開源倉庫數據進行了快照, 共 21TB.
然後使用 Piql 的技術將數據寫入到 186 個光敏膠片中. 最終儲存在了挪威 Svalbard
群島 Longyearbyen 小鎮一座廢棄礦井的數百米深坑中. 這將保存至少千年.

因為疫情, 時間有一些推遲, 但現在終於還是完成了.

所有相關的代碼貢獻者都獲得了 Arctic Code Vault Contributor 徽章.

我們向自然索取礦石, 現在向自然反饋代碼.

想想還是極浪(漫)的.

我身已死, 漏洞長存.
