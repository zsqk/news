## GitHub 投票

GitHub 的投票功能位於 Discussions 中, 有一個分類叫作 Polls.

Polls 有基礎的投票功能, 但不是表單那種複雜設計.

如果想要自定義分類也可以, 只需要將分類的 Discussion Format 設置為 Poll 即可.
但有兩個限制:

1. 已經設置為 Poll 的分類不能修改.
2. 其他分類不能改為 Poll 分類.

所以基本只能在創建分類的時候就選好 Poll 格式.

## GitHub 的投票相比釘釘/飛書群投票功能區別

1. GitHub 僅支持不投票即可查看結果功能.
2. GitHub 不支持不投票則不可查看結果功能.
3. GitHub 僅支持匿名投票.
4. GitHub 不支持查看投票者名單功能.
5. GitHub 不支持設置可投票者名單功能.
