在做 Web 設計的時候, 應該考慮色盲和色弱的人更方便使用軟件. 這部分內容常被稱作
accessibility, 縮寫為 a11y, 中文常被稱作無障礙.

## 色盲和色弱的基本認知

色盲和色弱是常見的視覺障礙，大約影響全球 8% 的男性和 0.5% 的女性人口。主要分為以下幾類：

- 紅色盲（紅色視覺缺陷）
- 綠色盲（綠色視覺缺陷）
- 藍色盲（藍色視覺缺陷）
- 全色盲（完全無法識別顏色）

## 設計原則

從設計角度, 應該區分兩種設計模式, 普通模式和色彩增強模式.
或者合併為一種設計模式, 支持色盲和色弱和普通用戶一樣正常與軟件進行交互.

一般的做法是除了顏色, 要給出額外的圖形信息. 比如做國內股市大盤設計時:

1. 漲, 不僅用紅色字體, 還要用向上的箭頭.
2. 跌, 不僅用綠色字體, 還要用向下的箭頭.

同時, 我們也可以注意使用高對比度顏色. 比如不同顏色時, 如紅色和綠色,
使用高對比度顏色, 那麼色盲和色弱的人也能很容易區分.

還有增加額外的線條來增加區分度.

## 技術實現

從前端角度, 如果設計單獨為色盲和色弱的人設計了一套 UI,
那麼儘量通過額外加載 CSS 的方式進行處理.

1. 基礎
2. 非色盲, 色弱
3. 色盲, 色弱

普通模式加載 1 + 2, 色彩增強模式加載 1 + 3.

也可以使用普通 + 擴展的方式:

1. 普通
2. 色盲, 色弱

色彩增強模式加載 1, 色彩增強模式加載 1 + 2. 要確保 2 覆蓋 1.

## 模擬與測試

對於 Web 開發來說, 可以通過 Chrome 的開發者工具, 來模擬色盲和色弱.

1. 打開 Chrome 開發者工具.
2. 選擇更多工具.
3. Rendering 中, 選擇 Emulate vision deficiencies.
4. 可以選擇一些情況進行模擬.
