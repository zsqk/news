React 19 終於正式發佈了: <https://react.dev/blog/2024/12/05/react-19>

新版本中新增了許多功能, 其中, 一些功能是我們重點關注的:

1. `useActionState`
2. `use`
3. `useOptimistic`
4. `ref` 作為 props 傳遞

## useActionState

在使用 useActionState 的時候, 我們需要注意的是, 在函數內部能否調用 setState
函數對數據進行部分修改.

官方演示非常清晰, 這裡稍作修改:

```tsx
function DataTable({ name }) {
  const [result, updateData, isPending] = useActionState(
    async (previousState, name) => {
      const result = await getDataPromise(name);
      return result;
    },
    new Result(),
  );

  return (
    <>
      <Table data={result} isPending={isPending} />
      <button
        type="submit"
        disabled={isPending}
        onClick={() => {
          updateData(name);
        }}
      >
        Update
      </button>
    </>
  );
}
```

## use

use 仍然不是一定足夠可靠的功能. 之前 React 團隊就說了 use 的侷限性, 現在
React 19 仍然沒有解決這個問題.

我們預期僅在初始化數據的時候使用 use, 在更新數據的時候仍使用 useState.
在組件中, 同時保有這兩種狀態管理的方式, 比如:

```tsx
function MyComponent() {
  const initData = use(getDataPromise());
  // 👆 因為現在不能在渲染組件中創建 Promise, 所以現在會報錯
  const [data, setData] = useState<Data | null>(null);
  const currentData = useMemo(() => data ?? initData, [data, initData]);

  return (
    <>
      {currentData}
      <button
        onClick={async () => {
          const data = await getDataPromise();
          setData(data);
        }}
      >
        Set Data
      </button>
    </>
  );
}
```

不過, 如何我們區分初始化數據和更新數據, 僅在系統初始化數據的時候使用 use,
那麼 use 仍然是一個非常有用的功能. 比如:

```tsx
const configPromise = getConfigPromise();

function MyComponent() {
  const config = use(configPromise);
  const [data, setData] = useState<Data | null>(null);

  return (
    <>
      {data}
      <button
        onClick={async () => {
          const data = await getDataPromise(config);
          setData(data);
        }}
      >
        Set Data
      </button>
    </>
  );
}
```

## useOptimistic

在上面的例子中, 我們區分了 initData, data 和 currentData. 在 React 19 中,
我們使用 useOptimistic 可以對前端預計修改成功的數據進行優化. 比如:

```tsx
function MyComponent() {
  const [data, setData] = useState<Data | null>(null);
  const [currentData, setOptimisticData] = useOptimistic(data);

  return (
    <>
      {currentData}
      <button
        onClick={async () => {
          setOptimisticData(tempData);
          const data = await getDataPromise(tempData);
          setData(data);
        }}
      >
        Set Data
      </button>
    </>
  );
}
```

在大多數情況下, 這是一個純優化, 並不會功能有影響.

這種優化甚至還有負面效果, 比如:

1. 如果用戶在點擊按鈕之後, 已經渲染了新的數據, 這時用戶認為已經完成.
2. 然後, 如果後端數據更新失敗, 那麼數據會重置回錯誤之前的數據, 但用戶不一定會注意到.

## ref 作為 props 傳遞

之前, ref 作為 props 傳遞的時候時會報錯. 需要使用 forwardRef 來傳遞.
但是, 現在 React 19 中, 不再需要使用 forwardRef 來傳遞, 可以直接傳遞 ref.

官方演示為:

```tsx
function MyInput({placeholder, ref}) {
  return <input placeholder={placeholder} ref={ref} />
}

//...
<MyInput ref={ref} />
```
