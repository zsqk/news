# 前言
通過瞭解哲學家們思考的問題能夠幫助我們更加簡單和通俗的認識到哲學是一門什麼樣的學科以及哲學家都在做些什麼事情。從而對哲學產生一個相對準確和客觀印象。

# 前蘇格拉底時代（公元前700~公元前370）
**前蘇格拉底時代對應中國的春秋戰國時期，老子，孔子的時代**

1. `泰勒斯`通過觀察水的形態變化提出`水是構成世界的基本材料`
2. `畢達哥拉斯`通過思考數學公式的確定性提出`數字是宇宙的統治者`
3. `普羅塔哥拉`提出`人是萬物的尺度`，因為一個人看起來是正確的事情，另一個人可能會認為是錯誤的。
4. `德謨克利特`提出原子論`世間是由原子和虛空組成的`

**前蘇格拉底時代的哲學問題大部門集中在對自然哲學的思考，比如客觀世界的原貌，萬物的構成。**

# 經典希臘時代（公元前470~公元前250）
**經典希臘時代對應中國的戰國時期**

1. `蘇格拉底`思考的問題是`什麼才是好的生活，生命的意義是什麼。提出善是事物的本性，是萬物追求的目標`
2. `柏拉圖`思考的問題是`人類如何分辨出萬物的正確的，完美的最本質的基本形態`。比如我們看到不同品種不同形態不同顏色的貓都能分辨出來，那麼必然所有的貓都有某種共同特徵。這種由共同特徵所組成的完美形態的貓才是我們應該去認識的。而現實世界只不過是這種完美形態的複製模型。    
為此`柏拉圖`提出一個“洞穴比喻”來說明。他讓人們想像出一個洞穴，囚犯面向牆壁被綁在洞穴中，身後是一個火堆。囚犯和火堆之間不時有人走動或拿起不同物體，這些物體的影子反映在洞穴牆壁上。那麼這些囚犯實際上並不能真正瞭解事物本身。柏拉圖覺得`人類感官所感知到的物質世界正如洞穴牆壁上的影子一樣，是現實的縮影`。    
這種對人類認識的質疑和問題通常被歸為`形而上學`。`形而上學`是哲學的一個門類，研究世界的本質。比如超自然世界的本原，靈魂是否存在，自由意志是否存在等。通常對於`形而上學`的理解誤區在於這一概念本身的形式，它不常與其他學科放在一起，我們會認為形而上學是一個概念而非學科。實際上它和數學，化學，物理學這些文字形式類似，當我們說某一問題是物理問題時，意味著這一問題屬於物理學範疇。而當我們說某一問題是形而上的，也就意味著這一問題屬於形而上學這門學科。
3. `亞裡士多德`與柏拉圖相反，柏拉圖質疑自己的感官，而`亞裡士多德`認為`我們是通過感知來認識世界的`。他認為現實世界中的物體並非物體完美形態的複製模型。我們應當通過研究個體來認識某一種類共有的本質。比如研究不同的貓得出貓共有的本質屬性。對於公正，美德這些概念，我們只能通過觀察他們在現實世界的各種不同呈現方式來逐漸修正對他們的瞭解和認識。    
`亞裡士多德`按照生物的特徵對生物進行了歸類。在這過程中制定了一套成系統的邏輯形式。期望運用邏輯推理出事實。例如，我們通過兩個命題“所有人都會死”和“蘇格拉底是人”可以推理出“蘇格拉底會死”的結論。
4. `伊壁鳩魯`認為`人應當在短暫的人生中享樂。這種快樂並不是純粹的身體感受到的世俗快樂，而是身體的沒有痛苦和靈魂的不受幹擾，是一種平靜狀態。`。
5. `芝諾`認為`宇宙有自己的規律，自然法則是宇宙的主宰。人應該遵循自然法則，追求各自與自然達成的和諧狀態`。

**從蘇格拉底開始，哲學家們開始關注對人本身的思考和探究。**

**受限於當時的知識水平，其中某些理論可能被現代人認為是簡單的，不值一提的，甚至是錯誤的，但我們也不能否認他們在自己所處的年代開創出這些理論的革命性，和對人類文明後續發展的重要性。現代的很多領域中我們仍然能夠清晰的看到這些理論所留下的印記。**
