---
title: 雲計算實例可以有多個 IP 嗎
categories: [cloud-computing, aws, aliyun]
---

對於運維, 什麼是雲服務? 雲服務有什麼好處? 雲服務提供商有區別嗎?

雲服務是為了節省運維開支的, 中小公司儘可能用雲.

今天有人問我, **一臺服務器可以有多個 IP 嗎?**

我回復說:

> 雲服務器計算，儲存，網絡都是分開的。一個計算可以有多個 IP。
> 就像我們電腦可以有多個網卡，可以連接不同貓獲得多個 IP。只不過雲上是虛擬的。

<img width="380" alt="Screen Shot 2020-03-27 at 13 01 58" src="https://user-images.githubusercontent.com/499364/77723538-b58c5900-702b-11ea-8b69-c0c4cd060a71.png">

但以上為理論, 我們沒有類似需求, 沒有實踐過. 出於謹慎, 我實操了一下:

- AWS 中國**支持**一個 EC2 實例多私網 IP 及多公網 IP. (僅限操作檯)
- 阿里雲 VPC **不支持**為一個 ECS 實例提供多個公網 IP. (僅限操作檯)

但需要注意, 我僅在 Web 操作檯上進行了操作, 沒有使用 CLI 工具. 不排除阿里雲在 API
層面提供更多功能的可能性. 因為以我們的經驗, 在安全組設置的時候, 有些不太安全的
設置在操作檯上被禁止, 但是在 API 層面是允許的.
