## node依賴管理
- Node的依賴管理工具
- 1. npm 
- 2. cnpm 
- 3. yarn
- 4. pnpm

## npm
- 1. 使用一個名為package.json的文件，用戶可以通過npm install --save命令把項目裡所有的依賴項保存在這個文件裡
- 2. npm安裝插件是從國外服務器下載，受網絡影響大，可能出現異常

## cnpm
- 1. cnpm跟npm用法完全一致, 服務器在國內, 訪問速度很快

## yarn
- 1. yarn是經過重新設計的嶄新的npm客戶端，它能讓開發人員並行處理所有必須的操作，並添加了一些其他改進
- 2. 運行速度得到了顯著的提升，整個安裝時間也變得更少
- 3. 像npm一樣，yarn使用本地緩存。與npm不同的是，yarn無需互聯網連接就能安裝本地緩存的依賴項，它提供了離線模式。
- 4. 允許合併項目中使用到的所有的包的許可證

## pnpm
- 1. pnpm運行起來非常的快，超過了npm和yarn
- 2. pnpm採用了一種巧妙的方法，利用硬鏈接和符號鏈接來避免複製所有本地緩存源文件，這是yarn的最大的性能弱點之一
- 3. pnpm繼承了yarn的所有優點，包括離線模式和確定性安裝
