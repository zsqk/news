當地時間2020年04月14日, GitHub 發文 [GitHub is now free for teams][0].

1. Free 不再限制私有倉庫及協作者數量.
2. Team 降價為每人每月 4 美元.

目前 Free 與 Team 的限制主要是私有倉庫的工作流了. 具體差別可以看 [1].

這裡列舉一些我認為重要的:

1. 合併代碼前強制要求 review.
2. 可為 issue 或 PR 指定多位 assignees.
3. 自動指定 code owners 進行 review.

GitHub 的這次變動主要瞄準的應該是 GitLab 的用戶. 從價格上做到了不輸於 GitLab.

但究竟有多少企業用戶會轉而選擇 GitHub 呢? 我不知道.

我們現在在用 GitLab, 暫時不會轉.

[1]: https://github.com/pricing
