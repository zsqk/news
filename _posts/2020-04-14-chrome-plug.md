# Chrome便捷插件
我們都知道Chrome 瀏覽器有一個好處，就是插件極其豐富。

### Octotree 樹形展示 Github 項目代碼
GitHub網頁連個側欄的文件樹沒有，查看很累，現在有很多開發者還是需要git clone下載到本地在把代碼裝到開發工具裡才能愉快的閱讀代碼。
這款Octotree讓你能像在GitHub上像在你的開發工具裡一樣瀏覽和搜索代碼。
- 下載地址：<https://chromecj.com/web-development/2017-10/840.html>

### 「FeHelper」WEB前端助手
目前包括 JSON自動/手動格式化、JSON內容比對、代碼美化與壓縮、信息編解碼轉換、二維碼生成與解碼、圖片Base64編解碼轉換、Markdown、 網頁油猴、網頁取色器、腦圖等貼心工具.

- 下載地址：<https://chromecj.com/web-development/2018-01/879.html>

### Fatkun圖片批量下載
找出當前頁面的所有圖片，提供按分辨率、鏈接等篩選圖片，只需點擊一下，即可下載頁面上選擇的所有圖像。可以使用你自己的規則下載圖像列表，可以批量重命名下載的圖像

- 下載地址：<https://chrome.google.com/webstore/detail/fatkun-batch-download-ima/nnjjahlikiabnchcpehcpkdeckfgnohf?hl=zh-CN>

### Baidu Capsule（百度網站淨化）
使用更純淨的百度，包括這幾個功能：
1.屏蔽百度推廣（就是為了它）
2.阻止百度追蹤 
3.美化首頁（個人感覺沒有用，很醜）

- 下載地址：<https://chrome.google.com/webstore/detail/%E7%99%BE%E5%BA%A6%E8%8D%AF%E4%B8%B8-baidu-capsule/ngiclcoldiplnjcafhjkacjcmdidcmjp?hl=zh-CN>
